# 选课班级匹配设计

## 根因

- 未来学期由两套教师 ID 复制出相同教师姓名、相同班级和相同排课，造成开课班重复。
- 后端选课仅校验重复选课与容量，没有比较学生班级和开课班班级。

## 目标

- 同一课程按开课班级区分，计科1班与计科2班使用不同上课时间和地点。
- 两个班级的课程均在选课中心展示。
- 学生点击非本班课程时拒绝选课，并显示“所选课程与班级不匹配”。
- 班级匹配校验必须由后端执行，前端继续展示后端业务错误。

## 实现

- 未来学期种子固定生成 3 门课程各两个班级，共 6 个开课班。
- 每门课程的1班与2班分别配置不同排课和教室。
- `StudentCourseServiceImpl.select()` 查询当前学生信息，并在写入选课记录前比较 `student.classId` 与 `offering.classId`。
- 班级不一致时抛出 `BusinessException("所选课程与班级不匹配")`。

## 验证

- 数据库中未来学期恰有 6 个开课班，课程各有1班和2班。
- 同一课程的两个班级排课不同。
- 计科2班学生选择1班课程被拒绝，选择2班课程成功。
- 后端测试、前端测试与构建全部通过。
