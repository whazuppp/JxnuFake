# 学期课表与选课范围调整设计

## 目标

- 课程表增加“2026-2027学年第1学期”选项，初始无已选课程。
- “2025-2026学年第1学期”按原型固定展示历史课程，不再显示空状态。
- 选课中心只允许选择“2026-2027学年第1学期”的开课班。
- 2025-2026学年两个学期的开课班均不出现在选课中心。

## 实现

- 数据库新增 2026-2027 学年第1学期及一批待选开课班，但不新增学生选课关系。
- 选课页面只保留目标学期，并始终使用该学期 ID 请求开课班与已选课程。
- 2025-2026 学年第1学期课表使用前端固定数据还原原型；其他学期继续读取后端课表。
- 学生选择或退选未来学期课程后，未来学期课表通过现有接口同步变化。

## 验证

- 历史第一学期能显示原型中的 11 门课程及排课。
- 未来第一学期初始课表为空。
- 选课中心只显示未来第一学期，且存在待选课程。
- 选中未来课程后课表可见，退选后消失。
- 前端测试与构建通过。
