# 毕业生图像采集页面规格

## 目标

将学生之家 / 公共服务 / 毕业生图像采集页面实现为一个可用的业务界面，而不是静态截图。页面需要完整呈现标题、表格、输入框、说明区与底部操作按钮，并保持与学校教务系统风格接近。

本次只实现前端主界面，不接入后端查询、保存或确认提交逻辑。

## 范围

页面限定在 `JxnuFrontEnd/src/views/studenthome/graduation.vue`。

保留以下业务感：

- 展示“江西师范大学毕业生图像采集信息校对表（本部）”标题。
- 展示红色提示文案“没有找到你的记录！”。
- 使用四列表格呈现学生字段。
- 提供“籍贯”和“手机号”两个可见输入框。
- 展示“提交”和“确认不再更改”两个灰色禁用按钮。
- 展示底部说明文案。

不包含以下内容：

- 不读取毕业生图像采集专用接口。
- 不实现按钮点击、保存、确认、校验或消息提示。
- 不新增路由、不改侧边菜单结构、不改后端。

## 数据设计

页面使用本地只读数据模型承接展示内容：

- 从 `localStorage` 中的 `loginUser` 读取学号、姓名等已有字段，能显示则显示。
- 其余字段使用空字符串作为默认值，保持表格完整但不伪造真实业务数据。
- “籍贯”和“手机号”为本地输入态，仅用于体现页面结构，不触发提交。

## 页面结构

页面分为四块：

1. 顶部标题区
2. 中部信息表格区
3. 底部按钮区
4. 说明文案区

表格按截图风格组织为左右两组字段：

- 左列标签：学号、性别、出生日期、籍贯、考生号、学制、院校代码、学院名称、班级名称、备注
- 右列标签：姓名、民族、身份证号、手机号、培养层次、办学类型、院校名称、专业名称、校验否

其中：

- “籍贯”单元格内展示输入框和格式提示。
- “手机号”单元格内展示输入框。
- “备注”占整行。

## 样式要求

- 使用白底、浅灰边框、紧凑表格、居中标题。
- 标题加粗并居中。
- 红色提示文案单独居中展示。
- 按钮视觉上与截图一致，为浅灰禁用态。
- 页面在窄屏下允许横向滚动，避免表格被压坏。

## 测试与验收

前端测试至少覆盖：

- 页面文件包含标题文案。
- 页面文件包含“没有找到你的记录！”提示。
- 页面文件包含“提交”和“确认不再更改”按钮，且为禁用态。
- 页面文件包含“籍贯”“手机号”“备注”“说明”等关键业务文案。

验收标准：

- 进入 `/studenthome/graduation` 可以看到完整主界面。
- 页面不是空白页。
- 两个按钮为灰色且不可点击。
- 页面整体结构与用户给定参考图一致，但保留前端页面自身实现逻辑。
